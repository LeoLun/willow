# 模板选择规范

## 需求

### R1: 模板内置与打包要求

系统 MUST 支持在应用的包资源目录中存储和组织模板。
在开发环境下，模板存放在 `app/work/templates/` 目录中。
在打包环境下，系统 MUST 从 `process.resourcesPath/templates/` 目录加载模板。
Electron Forge 的配置文件 `forge.config.mjs` 中 MUST 把 `./templates` 添加至 `packagerConfig.extraResource` 数组中，确保模板资源正确随包发布。

每个模板子目录下包含：
- `template.json`：包含模板描述及引用的元数据。字段必须包含 `id`（可选，默认文件夹名）、`name`（显示名称）、`description`（描述）、`zipFileName`（包含 skill + 代码的压缩包文件名）、`previewFileName`（可选，预览图文件名）。
- 预览图文件（如 `preview.png`）：对应 `previewFileName`。
- 压缩包文件（如 `金融管理.zip`）：对应 `zipFileName`。

### R2: 主进程模板扫描与 Base64 转换

主进程在接收到模板列表查询请求时，MUST：
1. 扫描包内置的 `templates/` 目录下的所有子文件夹。
2. 读取并解析各子文件夹下的 `template.json`。
3. 如果 `previewFileName` 对应文件存在，将其转换为 Base64 编码的 Data URL（支持 `png`/`jpg`/`jpeg`/`webp` 格式），在 `previewUrl` 字段中返回。
4. 排除无效模板（如缺少 `template.json` 或配置损坏的子文件夹）。
5. 即使没有模板，也应当返回空数组，不得抛出未捕获错误。

### R3: 创建工作空间支持拷贝与自动会话

当调用创建工作空间 API 时，若请求中携带了 `templateId`：
1. 主进程 MUST 从配置列表中定位该模板。
2. 创建好工作空间目录并插入工作空间数据库记录后，MUST 将该模板包下的 zip 文件拷贝至新创建的工作空间根目录。
3. 拷贝完成后，主进程 MUST 自动调用 `SessionService.createSession` 在新工作空间下创建一个新会话 (Session)。
4. 接口返回数据中 MUST 包含新创建的 `workspace`、自动生成的 `session` 以及对应拷贝的 `zipFileName`。

### R4: 模板选择 UI 与卡片展示

在创建工作空间的对话框（`CreateWorkspace.vue`）中，系统 MUST：
1. 在初始化时异步调用获取模板列表接口。
2. 如果可用模板列表不为空，则在“项目目录”选择区下方渲染“选择模板（可选）”区域。
3. 模板列表展示为响应式的卡片网格。每个卡片展示预览图、名称、描述。
4. 点击卡片能够选中当前模板，并具有清晰的选中高亮状态。再次点击或点击“不使用模板”按钮可以取消选中。
5. 点击“创建”提交表单时，若选中了模板，必须将选中的 `templateId` 作为参数一同发送给主进程。

### R5: 自动发送解压指令消息

当使用模板创建工作空间成功后，渲染进程 MUST 执行以下操作：
1. 刷新工作空间及会话列表。
2. 自动跳转路由至新会话的详情页：`router.push(`/${session.id}`)`。
3. 自动触发发送一条消息至 AI，内容为：`解压「${zipFileName}」包到当前目录`。其中 `zipFileName` 是对应模板定义的 zip 包文件名（例如：`金融管理.zip`）。
4. 展开侧边栏中该工作空间的节点，确保用户可以看见其会话。

---

## 验收标准

- [ ] 模板目录不存在或为空时，程序不报错，且返回空模板列表。
- [ ] 在 `app/work/templates/financial-management/` 放置 `template.json`、预览图和 zip 文件后，主进程能够正确解析并返回包含预览图 Base64 的列表数据。
- [ ] 创建新工作空间时显示模板选择区域，有卡片网格渲染，支持选中/取消选中高亮。
- [ ] 选中模板并点击“创建”后，工作空间目录被成功创建，且该模板对应的 zip 包（如 `金融管理.zip`）已被完整拷贝在工作空间根目录下。
- [ ] 拷贝成功后，会自动在此工作空间下生成一个新的会话，返回接口包含 `session` 字段。
- [ ] 渲染进程收到响应后自动导航至该新会话界面，并且聊天框中自动以用户身份发出消息 `解压「金融管理.zip」包到当前目录`。
- [ ] 侧边栏中对应的工作空间节点自动展开，显示出生成的会话。
